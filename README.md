# Tierheim-Umfrage Dashboard

Next.js-App zur visuellen Auswertung einer Tierheim-Umfrage mit Filterung nach Zielgruppen.

## Entwicklung

```bash
npm install
npm run dev
```

## Deployment

Die App ist fuer Vercel vorbereitet. Das CSV liegt innerhalb des Projekts unter `data/Umfrage.csv`
und wird serverseitig eingelesen.
